# The hush guide

hush takes the noise out of speech with RNNoise. These pages explain it from the beginning; read
them in order, or go straight to the one you need.

1. [Getting started](getting-started.md): install hush, build its native library, and denoise a
   first recording.
2. [Audio for hush](samples.md): the format hush takes, and turning samples into it and back.
3. [Denoising](denoising.md): denoisers, frames, streams, and how likely a frame is to be speech.
4. [How it works](architecture.md): the native library underneath, handles, memory and threads.
5. [Reference](modules.md): every type, constant and method on one page.
6. [Testing](testing.md): how hush is tested, and how to run the tests.
